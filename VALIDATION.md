# Проверки GDWorld Android

Дата: 21 ноября 2026.

- Kotlin-компиляция Debug проходит.
- Целевые JVM-тесты GDWorld: 4 проходят. Проверяются выход за каталог, абсолютные пути, обход через символическую ссылку, сохранение пользовательских данных и исключение настольных компонентов, безопасная очистка временных файлов без перехода по символическим ссылкам и URL-safe Base64 хешей Gravit.
- Серверный модуль собирается против библиотек Gravit 5.7.14. Изолированная проверка подтверждает отказ при отсутствующем/неизвестном хеше, принятие разрешённого хеша без авторизации пользователя и отказ повторной регистрации авторизованной сессии.
- ARM64 Debug APK собран; схема подписи v2 проверена через apksigner. Проверено наличие MobileGlues, libpojavexec, Android Java 21 и лицензии MobileGlues, отсутствие библиотек других архитектур.
- MobileGlues 2.0.0 взят из официального выпуска после проверки опубликованного SHA-256. Версия и хеши записаны в UPSTREAM.json.

## Ограничения проверки

Первый полный запуск JVM-тестов (до добавления последней проверки очистки): 16 тестов, 8 проходят, 8 падают. Два файловых теста требуют отсутствующий F:\Download\geckolib-forge-1.21.8-5.2.2.jar; шесть тестов сравнения версий падают при статической инициализации GameVersionNumber. Эти тесты и соответствующая логика базы не изменялись. CI запускает целевые проверки GDWorld.

Android-модуль установлен в рабочий Gravit с разрешения владельца. Живые протокольные проверки прошли: отказ неизвестному APK, регистрация разрешённого APK, регистрация временного CMS-аккаунта, отказ неверному паролю, CLIENT-вход с тем же UUID, получение профиля и файлов, скачивание с проверкой SHA-1, joinServer, отказ неверному игровому токену, OAuth refresh/restore. Временные аккаунты удалены. Игровой сервер не перезапускался. 2FA и отображение скинов в игре отдельно не проверены.

Физическое Android-устройство не подключено. Внешний вид на устройстве, сенсорное управление, GPU-рендеринг и работа актуальной сборки в игре не проверены. Сборка APK сама по себе не подтверждает запуск Minecraft.

Ключ подписи GDWorld хранится отдельно от репозитория. Для релизов GitHub требуются защищённые секреты, перечисленные в README.
