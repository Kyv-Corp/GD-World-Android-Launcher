- Физическое Android-устройство и запуск Minecraft/GPU не проверялись. Релиз остаётся тестовым. Автоматическая подпись/публикация через теговый CI ещё не подтверждена этим локальным выпуском.

## Исправления 0.1.1

- Реальный прогресс текущего шага GameInstaller, проверки файлов и скачанных байтов; этапы локализованы на пяти языках. Неопределённые операции не получают выдуманный процент.
- Задачи штатного запуска Minecraft показаны на главном экране, включая повторную проверку управляемой сборки. Исправлено преждевременное снятие состояния занятости при отмене задачи.
- Главный экран ограничивает ширину формы, использует компактную шапку и отступы для вырезов/клавиатуры; MainActivity настроена на adjustResize.
- Проверка обновлений использует Kyv-Corp и список релизов, включая prerelease; выбирает максимальный шестизначный код среди опубликованных сборок с непустым APK. SHA256SUMS не предлагается как устанавливаемый файл.
- В нативном мосте исправлены форматы числовых ошибок EGL (включая опасный %s) и возврат из потоковой функции VirGL. Настройка GPU/рендереров не менялась.
- Шесть PackFiles-тестов прошли отдельно через JUnit: пути/символические ссылки, очистка, правила контента, URL-safe SHA-1, реальные байты и границы чанков, отмена, пустой файл, неверные размер/хеш.
- Исправлены непереносимые файловые fixture-тесты, JVM-доступ к таблицам версий и некорректные примеры версий. Ручные тесты загрузки логов во внешние сервисы и ping чужого Minecraft-сервера явно помечены Ignore. CI запускает полный оставшийся JVM-набор.
- Проверки сопутствующих компонентов прошли: шесть тестов identity; кабинет в изолированном контейнере без сети; mod-sync и интерфейс ModsSite на fixture-данных; snapshot publisher; правила трёх настольных мини-игр; серверная регистрация Android-сборок. Рабочие аккаунты и данные игроков не изменялись.
- В настольном GitHub-репозитории подтверждён успешный запуск Publish launcher с событием schedule от 21 ноября 2026, 15:51:16 UTC; прежнее ограничение «запуск по расписанию не наблюдался» закрыто.
- Сайт вернул HTTP 200; контейнеры проекта и MCSManager активны, Minecraft слушал 25566. Эти проверки не заменяют вход в игру с телефона.

- Полный локальный `:ZalithLauncher:testDebugUnitTest` завершился успешно: 23 проверки, из них 20 выполнены, 3 ручные сетевые проверки пропущены. Все 9 целевых тестов GDWorld прошли. Kotlin/Java приложения скомпилированы.

- Локальные Debug и Release сборки проходят; опубликован подписанный Release APK 0.1.0 (`v000001`).
- Целевые JVM-тесты GDWorld: 4 проходят. Проверяются выход за каталог, абсолютные пути, обход через символическую ссылку, сохранение пользовательских данных и исключение настольных компонентов, безопасная очистка временных файлов без перехода по символическим ссылкам и URL-safe Base64 хешей Gravit.

## Ограничения проверки

Первый полный запуск JVM-тестов (до добавления двух последних тестов GDWorld): 16 тестов, 8 проходят, 8 падают. Два файловых теста требуют отсутствующий F:\Download\geckolib-forge-1.21.8-5.2.2.jar; шесть тестов сравнения версий падают при статической инициализации GameVersionNumber. Эти тесты и соответствующая логика базы не изменялись. Workflow CI настроен на целевые проверки GDWorld.

Android-модуль установлен в рабочий Gravit с разрешения владельца. Живые протокольные проверки прошли: отказ неизвестному APK, регистрация разрешённого APK, регистрация временного CMS-аккаунта, отказ неверному паролю, CLIENT-вход с тем же UUID, получение профиля и файлов, скачивание с проверкой SHA-1, joinServer, отказ неверному игровому токену, OAuth refresh/restore. Временные аккаунты удалены. Игровой сервер не перезапускался. 2FA и отображение скинов в игре отдельно не проверены.

Физическое Android-устройство не подключено. Внешний вид на устройстве, сенсорное управление, GPU-рендеринг и работа актуальной сборки в игре не проверены. Сборка APK сама по себе не подтверждает запуск Minecraft.

Ключ подписи GDWorld хранится отдельно от исходников. С явного разрешения владельца защищённые секреты подписи настроены в GitHub Actions. Фактическая автоматическая подпись и публикация через CI ещё не подтверждены завершённым прогоном.
