# Проверки GDWorld Android

Дата: 22 ноября 2026.

## Рабочая версия 0.1.3 — интерфейс расширенных возможностей

- Через ADB на Poco X3 Pro (`M2102J20SG`, Android API 31) воспроизведена исходная проблема. Физический экран 1080×2400, плотность 440 dpi, ширина окна 392 dp; `DisplayCutout` требует верхний отступ 91 px.
- Весь расширенный интерфейс использует safeDrawingPadding/imePadding. Верхняя панель на узком окне разделена на заголовок и прокручиваемые действия, заголовок ограничен своей шириной. В широком окне действия занимают не более 60% ширины, оставляя место навигации. Кнопки имеют высоту не менее 48 dp.
- Стрелка на главной расширенного меню вызывает возврат в GDWorld, во вложенных разделах использует штатный back dispatcher; домашняя кнопка расширенной навигации сохранена. Подпись возврата локализована на пяти языках.
- При ширине менее 600 dp домашний экран расширенного меню использует LazyColumn: аккаунт/запуск, быстрые команды и полноширинные карточки с ограниченной высотой. Настроенный контент домашней страницы сохранён; его внутренняя прокрутка ограничена 400 dp, чтобы избежать бесконечных ограничений вложенного LazyColumn.
- ADB использован только для чтения состояния и снимка исходной версии. Установка APK по USB не выполнялась. Новая компоновка и нажатия в новом APK на телефоне пока не проверены.

## Исправления 0.1.2

- Найдена гонка в JvmService: callback выхода JVM ставил отправку UDP-результата в корутину; ZLNativeInvoker.jvmExit сразу после callback завершает процесс. Приёмник в старом коде также привязывался к порту после запуска сервиса. Это позволяло потерять единственный результат и ждать бесконечно.
- Новый JvmExitSignal привязывает сокет синхронно до старта JVM. Результат отправляется синхронно перед завершением дочернего процесса, без глобального старого receiveMsg и без подмены неизвестного кода успехом. Некорректные пакеты отклоняются, ожидание поддерживает отмену, контролирует исчезновение процесса и ограничено по времени. Операции с единственным JVM-сервисом сериализованы.
- Вместо ожидания исчезновения всех дочерних процессов завершается только собственный :jvm; :game не затрагивается. Очистка принадлежит ожидающей корутине в finally. Тайм-аут преобразуется в обычную ошибку установки, чтобы TaskFlowExecutor не поглотил его как пользовательскую отмену.
- Java выбирается из javaVersion.majorVersion Minecraft, с совместимым встроенным runtime; для 1.21.1 сразу Java 21. Повторные попытки поддерживают 8 → 17 → 21 → 25. Номер процессора и фактический runtime отображаются вместо пустого Installing in the foreground; процент обновляется после проверки результатов процессора.
- Горизонтальная компоновка: отдельные панели запуска/управления и входа/прогресса; каждая прокручивается независимо. Операция подготовки хранится выше ветвей ориентации.
- Полный локальный JVM-набор: **32 проверки, 29 выполнены успешно, 3 ручные сетевые проверки пропущены**. Новые: 5 реальных loopback UDP-тестов (быстрый выход, отсутствие старого успеха, неверный пакет/длинный следующий код, освобождение порта, занятый порт) и 4 теста выбора Java по метаданным. Kotlin/Java приложения скомпилированы.
- Эти тесты не являются проверкой NeoForge на физическом телефоне. Реальная установка, горизонтальная UI с клавиатурой и игровой запуск на Android ещё требуют проверки устройством.

## Исправления 0.1.1

- Реальный прогресс текущего шага GameInstaller, проверки файлов и скачанных байтов; этапы локализованы на пяти языках. Неопределённые операции не получают выдуманный процент.
- Задачи штатного запуска Minecraft показаны на главном экране, включая повторную проверку управляемой сборки. Исправлено преждевременное снятие состояния занятости при отмене задачи.
- Главный экран ограничивает ширину формы, использует компактную шапку и отступы для вырезов/клавиатуры; MainActivity настроена на adjustResize.
- Проверка обновлений использует Kyv-Corp и список релизов, включая prerelease; выбирает максимальный шестизначный код среди опубликованных сборок с непустым APK. SHA256SUMS не предлагается как устанавливаемый файл.
- В нативном мосте исправлены форматы числовых ошибок EGL (включая опасный %s) и возврат из потоковой функции VirGL. Настройка GPU/рендереров не менялась.
- Шесть PackFiles-тестов прошли отдельно через JUnit: пути/символические ссылки, очистка, правила контента, URL-safe SHA-1, реальные байты и границы чанков, отмена, пустой файл, неверные размер/хеш.
- Исправлены непереносимые файловые fixture-тесты, JVM-доступ к таблицам версий и некорректные примеры версий. Ручные тесты загрузки логов во внешние сервисы и ping чужого Minecraft-сервера явно помечены Ignore. CI запускает полный оставшийся JVM-набор.
- Проверки сопутствующих компонентов прошли: шесть тестов identity; кабинет в изолированном контейнере без сети; mod-sync и интерфейс ModsSite на fixture-данных; snapshot publisher; правила трёх настольных мини-игр; серверная регистрация Android-сборок. Рабочие аккаунты и данные игроков не изменялись.
- В настольном GitHub-репозитории подтверждён успешный запуск Publish launcher с событием schedule от 21 ноября 2026, 15:51:16 UTC; прежнее ограничение «запуск по расписанию не наблюдался» закрыто.

## Ограничения проверки

Первый полный запуск JVM-тестов (до добавления двух последних тестов GDWorld): 16 тестов, 8 проходят, 8 падают. Два файловых теста требуют отсутствующий F:\Download\geckolib-forge-1.21.8-5.2.2.jar; шесть тестов сравнения версий падают при статической инициализации GameVersionNumber. Эти тесты и соответствующая логика базы не изменялись. Workflow CI настроен на целевые проверки GDWorld.

Android-модуль установлен в рабочий Gravit с разрешения владельца. Живые протокольные проверки прошли: отказ неизвестному APK, регистрация разрешённого APK, регистрация временного CMS-аккаунта, отказ неверному паролю, CLIENT-вход с тем же UUID, получение профиля и файлов, скачивание с проверкой SHA-1, joinServer, отказ неверному игровому токену, OAuth refresh/restore. Временные аккаунты удалены. Игровой сервер не перезапускался. 2FA и отображение скинов в игре отдельно не проверены.

Физическое Android-устройство не подключено. Внешний вид на устройстве, сенсорное управление, GPU-рендеринг и работа актуальной сборки в игре не проверены. Сборка APK сама по себе не подтверждает запуск Minecraft.

Ключ подписи GDWorld хранится отдельно от исходников. С явного разрешения владельца защищённые секреты подписи настроены в GitHub Actions. Фактическая автоматическая подпись и публикация через CI ещё не подтверждены завершённым прогоном.
